Générateur de prompt de correction

Renseignez le sujet, le corrigé, le barème et les compétences : le prompt produit est à coller dans une conversation Claude en navigation privée, avec les copies en pièces jointes.

Avant d'envoyer les copies : masquez les noms des élèves (numéro ou code à la place). Relisez toujours les notes proposées : l'IA assiste la correction, elle ne la remplace pas.
