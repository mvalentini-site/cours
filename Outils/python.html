Coller un tableau

Sélectionner les colonnes dans le tableur (Excel, LibreOffice, Regressi, outil Tableur-grapheur…), les copier, puis les coller ci-dessous, avec la ligne des titres.
Le programme est enregistré automatiquement dans ce navigateur. input() attend la réponse dans la zone Résultat (valider avec Entrée) ; pour les nombres, utiliser float(input(...)) et le point décimal (2.5, pas 2,5). plt.show() affiche le graphique dans le résultat. Données : ajouter un fichier de mesures (ou le glisser sur la page), puis cliquer sur son nom pour insérer le code qui le lit ; les fichiers enregistrés par le programme (open(..., "w"), plt.savefig) apparaissent aussi et se téléchargent. Le bouton Stop (ou Échap) arrête un programme trop long ou une boucle infinie. Le premier lancement télécharge Python (une dizaine de Mo) ; les suivants sont plus rapides.
